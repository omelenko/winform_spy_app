Це маленький додаток що слідкує за вашими діями (нажаті клавіші та відкриті програми) який я зробив під час свого першого
вивчення WinForm C# як курсовий проект.

Основні функції:

Додаток має 3 режими:

1. Налаштування
В цьому режимі ви вносите список "заборонених" слів та програм, вибираєте режим роботи (є два Слідкування та Модерування),
задаєте розташування файлу для звітності.
2. Слідкування
Власне основний режим роботи додатку де всі нажаті вами клавіші та відкриті програми записуються в звіт.
3. Перегляд файлу звіту
Файл звіту відкривається в блокноті.

This is a small WinForm app that spies on you pressing keyboard buttons and opening apps that i made during my first
time learning WinForm C# as a course project.

Main functionality:

The app has 3 modes:

1. Setup
In this mode you fill lists of "banned" words and apps, choose a job (there are 2, Following and Moderation),
choose your raport file.
2. Following
The main mode where all your key pressed and opened programs are written down into the raport file.
3. View raport file
Raport file is opened in notepad
